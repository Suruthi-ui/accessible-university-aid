# AccessU Connect

Build a polished AI-powered university accessibility assistant called "AccessU".

Purpose:

Create a smart university platform that helps students with disabilities request academic and campus support and helps volunteers find suitable support opportunities.

Target users:

1. Students with disabilities

2. Student volunteers

3. University accessibility/support coordinators

Core features:

1. Landing page

- Product name: AccessU

- Subtitle: "Smart Accessibility Support for Every Student"

- Explain briefly how the platform connects students who need support with suitable volunteers.

- Add clear buttons: "Request Support" and "Become a Volunteer"

2. Student Support Request

Create a form where a student can enter:

- Student name

- Student ID

- Disability/support category

- Support required

- Date

- Time

- Location

- Urgency

- Additional details

Support categories can include:

- Scribe assistance

- Reader assistance

- Note-taking assistance

- Mobility assistance

- Communication assistance

- Exam assistance

- Campus activity assistance

3. Smart Volunteer Matching

Create a matching feature that recommends suitable volunteers based on:

- Support category

- Volunteer skills

- Availability

- Experience

- Previous performance/rating

- Location

Show recommended volunteers as cards with:

- Name

- Skills

- Experience

- Availability

- Rating

- Match percentage

- "Request Volunteer" button

4. AI Accessibility Assistant

Add an AI chat assistant that helps students:

- Understand what support they can request

- Choose the appropriate support category

- Explain how to submit a request

- Answer general accessibility-related questions

5. Volunteer Dashboard

Create a dashboard showing:

- Available support requests

- Volunteer skills

- Availability

- Accepted requests

- Completed requests

- Performance rating

6. Coordinator Dashboard

Create a simple university coordinator dashboard showing:

- Total students

- Active support requests

- Available volunteers

- Matched requests

- Completed requests

7. Accessibility

Make the application itself accessible:

- Clear typography

- Good contrast

- Large readable buttons

- Keyboard-friendly controls

- Responsive design

- Simple navigation

- Screen-reader-friendly labels

8. Design

Use a modern, professional university technology design.

Use clean cards, subtle animations, good spacing and a polished dashboard.

Do not make it look like a generic template.

9. AI

Use an AI model for the accessibility assistant and smart volunteer recommendation explanation.

The AI should explain why a volunteer is a good match instead of only showing a percentage.

10. Demo-friendly behavior

The application must work well as a hackathon prototype.

Use realistic sample students, volunteers and support requests so the dashboards are not empty.

Do NOT add:

- Payment

- Complex authentication

- Unnecessary social features

- E-commerce

- Overly complicated features

Make this a working full-stack web application, not a static landing page.
